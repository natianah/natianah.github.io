## Structure

```
natianah.github.io/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── profil.jpg
    └── favicon.svg
```

## Déploiement sur GitHub

1. Crée les dossiers `css`, `js`, `assets` dans ton repo `natianah.github.io`.
2. Remplace `index.html` par cette nouvelle version.
3. Ajoute `css/style.css` et `js/script.js`.
4. Déplace tes fichiers `profil.jpg` et `favicon.svg` existants dans `assets/`.
5. Commit + push. GitHub Pages se met à jour en 1-2 minutes.

## Ce qui a changé

- **Tous les emojis remplacés par des icônes SVG** (dégradé bleu conservé, sprite d'icônes en haut du `<body>`, référencées via `<use href="#i-nom">`). Elles s'adaptent automatiquement à la couleur du thème clair/sombre.
- Les drapeaux emoji (🇲🇬🇫🇷🇺🇸) sont remplacés par des badges ronds avec le code du pays (MG / FR / EN), plus lisible et cohérent sur toutes les plateformes.
- Structure toujours en 3 fichiers (html/css/js) pour un repo plus propre.
- Design et contenu identiques à ta version glassmorphism actuelle, juste plus "pro" visuellement.

## À personnaliser

- Remplace les 4 `LIEN_DRIVE_x` dans `index.html` par tes vrais liens Google Drive.
- Si tu veux ajuster une icône précise (ex: en changer une qui ne te plaît pas), dis-le moi — chaque icône est un simple `<symbol>` dans le sprite, facile à remplacer.
